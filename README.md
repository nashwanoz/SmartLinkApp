# خمر نت — Khamr Net

نظام نقاط بيع ومخزون عربي يعمل دون اتصال، مبني بـ Kotlin وJetpack Compose وRoom. يدعم المدير والكاشير، المخزون الفرعي لكل مستخدم، الصندوق المستقل، المبيعات النقدية والآجلة، السندات، التسويات، التقارير، كشف الحساب بصيغة PDF، مزامنة Firebase الاختيارية، والطباعة ومشاركة الفاتورة عبر WhatsApp.

## التشغيل

1. افتح مجلد `khamr-net-android` في Android Studio Ladybug أو أحدث.
2. شغّل التطبيق على جهاز Android 8.0 أو أحدث.
3. حساب المدير الافتراضي عند أول تشغيل: اسم المستخدم `المدير العام`، كود المستخدم `1`، وكلمة المرور `1`.
4. لتمكين المزامنة، ضع ملف Firebase الحقيقي باسم `app/google-services.json`. التطبيق يبقى يعمل محليًا إذا لم يوجد الملف.

## التجميع عبر GitHub Actions

يوجد ملف التجميع في:

`.github/workflows/android.yml`

بعد رفع مجلد المشروع إلى مستودع GitHub، شغّل workflow باسم **Build Khamr Net Android** من تبويب **Actions** أو ادفع تغييرًا إلى فرع `main` أو `master`. سيظهر ملف `khamr-net-debug-apk` في قسم **Artifacts** بعد اكتمال البناء.

المزامنة مع Firebase اختيارية. عند توفر ملف Firebase الحقيقي، ضعه باسم `app/google-services.json`؛ سيُفعّل المشروع إضافة Google Services تلقائيًا أثناء البناء. بدون الملف سيستمر التطبيق محليًا، وسيظهر زر اختبار Firebase رسالة توضح أن الإعداد غير موجود.
يوجد زر **اختبار Firebase** داخل شاشة **بيانات الأصناف**. الاختبار ينفذ كتابة حقيقية إلى المسار `connection_tests/<device-id>` للتأكد من إعداد التطبيق وقواعد Realtime Database.

## ما تم تثبيته في هذه النسخة

- اسم المستخدم نص حر، بينما كود المستخدم وكلمة المرور رقميان ويظهر لهما كيبورد الأرقام.
- كود المستخدم فريد ولا يمكن تسجيل مستخدم آخر بالكود نفسه، والمدير يستطيع تعديل بيانات المستخدم وكلمة مروره.
- أرقام الفواتير وسندات القبض والصرف قصيرة وواضحة: `السنة + كود المستخدم + نوع المستند + تسلسل 4 أرقام`.
- نوع المستند `3` لسند القبض، `1` لسند الصرف، و`4` لفاتورة المبيعات. مثال المستخدم 2 في عام 2026: `26230001` لسند قبض و`26240001` لفاتورة.
- شاشة فواتير المبيعات والتقارير متاحة من الرئيسية، مع إجماليات المبيعات والعهدة وحركة المستخدمين والعملاء.
- كشف حساب العميل يُشارك كملف PDF، ويعرض الرصيد الدائن على أنه «له» والمدين على أنه «عليه».
- الوحدة الكبيرة الافتراضية `كرت` وسعتها الافتراضية `60`، وكل الحقول الرقمية تستخدم كيبورد الأرقام.
- اختبار Firebase والمزامنة ينفذان عمليات الانتظار على خيط الخلفية لتجنب خطأ `Must not be called on the main application thread`.

## ملاحظات مهمة

- يتم إنشاء أرقام المستندات محليًا لكل سنة وكود مستخدم ونوع مستند، مع تسلسل يبدأ من `0001`.
- كل عمليات البيع والتحويل والسندات والتسويات تُحفظ محليًا أولًا بعلامة `posted = 0`.
- عامل WorkManager يرسل العمليات غير المنشورة إلى Firebase، ثم يضعها `posted = 1` بعد النجاح.
- يلزم منح صلاحية Bluetooth من إعدادات الجهاز للطباعة على الطابعات الحرارية.
